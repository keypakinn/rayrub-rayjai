# รายรับ-รายจ่าย

เว็บแอป (PWA) บันทึกรายรับรายจ่ายส่วนตัวบน iPhone ข้อมูลทั้งหมดเก็บในเครื่อง (IndexedDB) ไม่มีเซิร์ฟเวอร์ ไม่มีบัญชีผู้ใช้ ใช้งานออฟไลน์ได้ และส่งออกเป็น Excel / CSV ไปทาง LINE ได้

## ติดตั้งบน iPhone
1. เปิดลิงก์ GitHub Pages ของ repo นี้ใน **Safari**
2. แตะปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
3. ต่อจากนี้เปิดจากไอคอนเท่านั้น (ข้อมูลใน Safari กับในไอคอนแยกกัน)

## ใช้งานเป็นประจำ
- ส่งออกไฟล์เก็บไว้เป็นระยะ: ตั้งค่า → ส่งออก → สร้างไฟล์ → แชร์ไป LINE
- ถ้าล้างข้อมูล Safari ลบไอคอน หรือเปลี่ยนเครื่อง ข้อมูลจะหาย กู้คืนได้จาก ตั้งค่า → นำเข้าจากไฟล์

## ไฟล์ Excel
ชีต `รายการ` เป็น Excel Table 1 แถวต่อ 1 รายการ พร้อมทำ Pivot
คอลัมน์: รหัส · วันที่ · ปี · เดือน · ประเภท · หมวด · หมวดย่อย · ช่องทาง · ยอด · ยอดสุทธิ · รายการผ่อน · งวด · ทริป · โน้ต

## โครงสร้างโค้ด
| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html`, `app.css` | หน้าเว็บและหน้าตา (ธีมมืด) |
| `sw.js` | เก็บไฟล์แอปไว้ใช้ออฟไลน์ + แจ้งเวอร์ชันใหม่ |
| `js/db.js` | อ่าน/เขียน IndexedDB |
| `js/store.js` | ข้อมูลและกติกา: บันทึก ผ่อน รายการประจำ ทริป |
| `js/excel.js` | ส่งออก xlsx/csv และนำเข้า |
| `js/ui.js` | โครงหน้าจอ แผ่นล่าง กล่องถาม ข้อความแจ้ง |
| `js/v-*.js` | แต่ละหน้า: บันทึก สรุป รายการ ผ่อน ตั้งค่า |
| `vendor/exceljs.min.js` | ไลบรารี ExcelJS 4.4.0 (MIT) สำหรับสร้างไฟล์ Excel |

## ปล่อยเวอร์ชันใหม่
แก้โค้ดแล้วเปลี่ยน `VERSION` ใน `sw.js` (และ `APP_VERSION` ใน `js/v-settings.js`) ทุกครั้ง แอปในเครื่องจะขึ้นแถบ "มีเวอร์ชันใหม่ แตะเพื่ออัปเดต" ข้อมูลเดิมไม่หาย
